# Web Calculator App

A clean, responsive, and functional web-based calculator built using vanilla **HTML5**, **CSS3**, and **JavaScript (ES6)**. This project demonstrates basic DOM manipulation, state management, and event handling in JavaScript.

## 🚀 Features

- **Basic Arithmetic Operations**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Additional Operations**:
  - Percentage calculation (`%`)
  - Square root calculation (`√`)
- **Decimal Support**: Handles decimal values without duplicating points.
- **Clear Screen**: Dedicated `AC` (All Clear) button to reset the calculator state.
- **Responsive & Modern UI**: Built with CSS Grid and Flexbox for a clean layout and active button feedback.

## 📁 Project Structure

```text
├── index.html   # Main HTML markup and structure
├── style.css    # Layout styling, colors, and responsive design
└── script.js    # Calculator state management and operational logic
```

## 🛠️ Built With

- **HTML5**: Structured semantic elements and calculator layout.
- **CSS3**: Modern layout using Grid/Flexbox, custom styling, and interaction feedback.
- **JavaScript**: Functional programming logic, event listeners, and DOM updates.

## ⚙️ How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/calculator-app.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd calculator-app
   ```
3. **Open the project**:
   - Double-click `index.html` to open it directly in your web browser.
   - Alternatively, run it using a local server like Live Server in VS Code.
